### Bogdan Shcherbinin — Python backend developer

Пишу асинхронные Telegram-боты, API и автоматизацию: от идеи до сервера.
Стек — Python/FastAPI/asyncio, Playwright и Telethon для парсинга и
автоматизации браузера, деплой и настройка VPS. Предпочитаю локальные и
self-hosted решения облачным, где это возможно (Ollama, ComfyUI, LM Studio).

**Стек:** Python · FastAPI · asyncio · aiogram · SQLAlchemy · Playwright ·
Telethon · pandas · PostgreSQL/SQLite · Docker · Linux/VPS

**Чем занимаюсь:**

- Telegram-боты любой сложности: FSM-сценарии, платежи (Stars/ЮKassa/крипта),
  Mini Apps на React с проверкой Telegram initData.
- Backend на FastAPI: REST API, аутентификация (JWT/bcrypt), интеграции с
  внешними сервисами и панелями управления.
- Автоматизация и веб-скрапинг на Playwright — headless-браузер, обход
  антибот-защит, извлечение и структурирование данных.
- Развёртывание и настройка серверов: systemd, Caddy/nginx, VPN-инфраструктура
  (3x-ui/Xray, VLESS+Reality), бэкапы и мониторинг.
- Локальные ИИ-инструменты: Ollama, ComfyUI, LM Studio — интеграция моделей
  в свои сервисы без облачных API.
